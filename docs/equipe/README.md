# Guia da equipe (para pessoas e agentes)

Regras de trabalho que valem para **qualquer agente** (Claude, Codex, outro) e para quem programa sem agente. As regras do projeto estão no `CLAUDE.md` da raiz; aqui fica o **como trabalhar bem**: o que conferir numa revisão, como testar e corrigir, e os erros que já custaram tempo.

| Arquivo | Quando ler |
|---|---|
| [checklist-revisao.md](checklist-revisao.md) | Ao revisar uma tarefa (QA) ou antes de dizer que ela está pronta |
| [testar-e-corrigir.md](testar-e-corrigir.md) | Ao escrever testes ou corrigir um bug |
| [licoes.md](licoes.md) | Antes de começar uma tarefa: os erros que não podem se repetir |

**Como manter:** quem aprender algo que vale para toda a equipe (um erro que custou tempo, uma armadilha de biblioteca) acrescenta uma entrada curta em `licoes.md`, de forma geral, com "o que aconteceu" e "como evitar". O que é só o estado do trabalho vai na `memoria.md`.
